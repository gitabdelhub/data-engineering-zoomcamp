@@ brief
- La couche **ingestion** copie les données de la source telles quelles. Ici, deux assets : `ingestion.trips`, en Python, et `ingestion.payment_lookup`, un **seed**.
- Un asset Python commence par un bloc `"""@bruin ... @bruin"""`. Sa fonction `materialize()` renvoie un **DataFrame**, et Bruin le charge lui-même dans la base : pas de code de connexion à écrire.
- `image: python:3.11` dit quelle version de Python utiliser. Bruin crée un environnement isolé avec uv et y installe le `requirements.txt` le plus proche de l'asset.
- La stratégie `append` **ajoute** les lignes à chaque run, sans jamais rien effacer. Les doublons se traitent plus loin, dans le staging.
- Un **seed** (`duckdb.seed`) charge un petit CSV du projet comme une table, avec ses contrôles qualité.

@@ codespaces
- Les fichiers viennent de `https://d37ci6vzurychx.cloudfront.net/trip-data/`, le site de la ville de New York, au format parquet : `green_tripdata_2019-01.parquet`, par exemple.
- Pour un mois, donne la fenêtre complète : `--start-date 2019-01-01 --end-date "2019-01-31 23:59:59.999999"`. C'est la forme que Bruin utilise lui-même par défaut (la veille, jusqu'à 23:59:59.999999). La leçon 7 te montre ce qui arrive avec `--end-date 2019-01-31` seul.
- Le premier run d'un asset Python installe Python 3.11 et les paquets : compte une minute. Les suivants réutilisent l'environnement.

@@ hints
- La boucle des mois : commence à `start.replace(day=1)` et continue **tant que** le mois est `<= end`. Avec `<`, une fenêtre d'un seul mois ne téléchargerait rien.
- `pd.concat(frames, ignore_index=True)` assemble les DataFrames des différents fichiers.
- Le préfixe des dates : `"tpep" if taxi_type == "yellow" else "lpep"`.
- `extracted_at` : `datetime.now(timezone.utc)`, ajouté une seule fois au DataFrame final.

@@ solution
`mon-pipeline/pipeline/assets/ingestion/trips.py` :

~~~python
"""@bruin
name: ingestion.trips
type: python
image: python:3.11
connection: duckdb-default

materialization:
  type: table
  strategy: append        # la couche brute garde tout ; le staging dédoublonne

columns:
  - name: taxi_type
    type: string
    description: "yellow ou green"
  - name: pickup_datetime
    type: timestamp
    description: "Prise en charge"
  - name: dropoff_datetime
    type: timestamp
    description: "Dépose"
@bruin"""

import json
import os
from datetime import datetime, timezone

import pandas as pd
from dateutil.relativedelta import relativedelta

BASE_URL = "https://d37ci6vzurychx.cloudfront.net/trip-data"


def months_between(start, end):
    """Le premier jour de chaque mois de la fenêtre, fin incluse."""
    current = start.replace(day=1)
    while current <= end:
        yield current
        current += relativedelta(months=1)


def materialize():
    start = datetime.fromisoformat(os.environ["BRUIN_START_DATE"])
    end = datetime.fromisoformat(os.environ["BRUIN_END_DATE"])
    taxi_types = json.loads(os.environ["BRUIN_VARS"]).get("taxi_types", ["yellow"])

    frames = []
    for taxi_type in taxi_types:
        prefix = "tpep" if taxi_type == "yellow" else "lpep"
        for month in months_between(start, end):
            url = f"{BASE_URL}/{taxi_type}_tripdata_{month:%Y-%m}.parquet"
            print(f"Téléchargement de {url}")
            df = pd.read_parquet(url)
            # les mêmes noms pour les verts et les jaunes
            df = df.rename(columns={
                f"{prefix}_pickup_datetime": "pickup_datetime",
                f"{prefix}_dropoff_datetime": "dropoff_datetime",
                "PULocationID": "pickup_location_id",
                "DOLocationID": "dropoff_location_id",
            })
            df = df[["pickup_datetime", "dropoff_datetime", "pickup_location_id",
                     "dropoff_location_id", "fare_amount", "payment_type"]]
            df["taxi_type"] = taxi_type
            frames.append(df)

    result = pd.concat(frames, ignore_index=True)
    result["extracted_at"] = datetime.now(timezone.utc)   # pour savoir quel chargement est le plus récent
    return result
~~~
