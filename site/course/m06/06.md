@@ constraints

@@ guide
### 1. Les mêmes colonnes

Renomme les dates avec `withColumnRenamed`. Pour les colonnes communes, compare `df_green.columns` et `df_yellow.columns` : une boucle, ou `set(...) & set(...)`, en gardant l'ordre des verts.

### 2. L'union

Un exemple sur des ventes :

~~~python
from pyspark.sql import functions as F

paris = paris.select(common).withColumn("city", F.lit("paris"))
lyon = lyon.select(common).withColumn("city", F.lit("lyon"))
sales = paris.unionByName(lyon)
sales.createOrReplaceTempView("sales")
spark.sql("SELECT city, COUNT(1) FROM sales GROUP BY city").show()
~~~

### 3. Le rapport

La requête de la vidéo est dans le texte de la leçon officielle, plus bas. Lis-la, puis écris la tienne : `date_trunc('month', pickup_datetime)` pour le mois, `PULocationID` pour la zone, et un `WHERE` sur la période.

### 4. L'écriture

`df_result.coalesce(1).write.parquet("data/report/revenue/", mode="overwrite")`.

@@ hints
- `set` ne garde pas l'ordre : `[c for c in df_green.columns if c in set(df_yellow.columns)]` le garde.
- Il y a 18 colonnes communes, une fois les deux dates renommées.
- Pour la période, une borne inclusive et une exclusive : `>= '2020-01-01'` et `< '2021-08-01'`.
- Si le nombre de mois n'est pas 19, ton filtre a un trou.

@@ solution
`rapport.py` :

~~~python
from pyspark.sql import SparkSession, functions as F

spark = SparkSession.builder.master("local[*]").appName("rapport").getOrCreate()

df_green = spark.read.parquet("data/pq/green/*/*") \
    .withColumnRenamed("lpep_pickup_datetime", "pickup_datetime") \
    .withColumnRenamed("lpep_dropoff_datetime", "dropoff_datetime")
df_yellow = spark.read.parquet("data/pq/yellow/*/*") \
    .withColumnRenamed("tpep_pickup_datetime", "pickup_datetime") \
    .withColumnRenamed("tpep_dropoff_datetime", "dropoff_datetime")

yellow_columns = set(df_yellow.columns)
common_columns = [c for c in df_green.columns if c in yellow_columns]
print(len(common_columns), "colonnes communes")

trips = df_green.select(common_columns).withColumn("service_type", F.lit("green")) \
    .unionByName(df_yellow.select(common_columns).withColumn("service_type", F.lit("yellow")))
trips.createOrReplaceTempView("trips_data")

spark.sql("SELECT service_type, COUNT(1) AS trips FROM trips_data GROUP BY service_type").show()

df_result = spark.sql("""
SELECT
    PULocationID AS revenue_zone,
    date_trunc('month', pickup_datetime) AS revenue_month,
    service_type,
    SUM(total_amount) AS revenue_monthly_total_amount,
    COUNT(1) AS total_monthly_trips,
    AVG(trip_distance) AS avg_monthly_trip_distance
FROM trips_data
WHERE pickup_datetime >= '2020-01-01' AND pickup_datetime < '2021-08-01'
GROUP BY 1, 2, 3
""")
df_result.coalesce(1).write.parquet("data/report/revenue/", mode="overwrite")
print(df_result.count(), "lignes,", df_result.select("revenue_month").distinct().count(), "mois")
spark.stop()
~~~

La sortie : 18 colonnes communes, 2 304 517 verts et 39 649 199 jaunes, puis `9683 lignes, 19 mois`.

@@ breakfix
Un collègue écrit l'union avec `unionAll`, et sélectionne les colonnes des jaunes dans l'ordre alphabétique : `df_yellow.select(sorted(common_columns))`. Lance son code et lis l'erreur. Puis, deuxième essai : il garde ton ordre, mais échange seulement `fare_amount` et `tip_amount` dans la liste des jaunes. Y a-t-il encore une erreur ? Compare la somme des pourboires des jaunes avant et après. Comment éviter les deux ?

@@ breakfix-hints
- `unionAll` ne regarde pas les noms : il colle la colonne 1 sous la colonne 1.
- Spark ne lève une erreur que si les **types** ne collent pas.
- `fare_amount` et `tip_amount` sont deux `double`.

@@ breakfix-answer
Premier essai : `[INCOMPATIBLE_COLUMN_TYPE] UNION can only be performed on tables with compatible column types. The second column of the second table is "INT" type which is not compatible with "TIMESTAMP"...`. Dans l'ordre alphabétique, la deuxième colonne des jaunes est `PULocationID`, sous le `pickup_datetime` des verts. Deuxième essai, pire : **aucune erreur**. Les deux colonnes ont le même type, Spark les empile, et les pourboires des jaunes sont maintenant leurs tarifs : un rapport faux, sans aucun message. `unionAll` (comme `union`) associe les colonnes **par position**. `unionByName` les associe **par nom** et refuse si un nom manque : c'est lui qu'il faut prendre quand deux DataFrames viennent de sources différentes.
