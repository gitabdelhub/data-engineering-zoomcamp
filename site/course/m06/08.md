@@ brief
- `a.join(b, on=["hour", "zone"], how="outer")` joint deux DataFrames sur des colonnes de même nom. `how` vaut `inner` (par défaut), `left`, `right` ou `outer`.
- Pour joindre deux **grandes** tables, Spark fait un **sort-merge join** : il mélange les deux côtés par clé (un shuffle de chaque côté), trie, puis assemble.
- Quand un côté est **petit** (la table des 265 zones), Spark l'envoie en entier à chaque executor : c'est un **broadcast join**, sans shuffle de la grande table. `F.broadcast(df)` le demande explicitement.
- `df.explain()` affiche le plan : `SortMergeJoin` ou `BroadcastHashJoin` te dit lequel Spark a choisi.

Les lignes en plus sont les couples (heure, zone) où **seuls des taxis verts** ont roulé : une jointure externe garde les clés des deux côtés. Dans une ligne qui n'a que des jaunes, `green_amount` vaut `null`, pas 0. Si tu veux un 0 pour un rapport, `F.coalesce(F.col("green_amount"), F.lit(0))` ou `fillna(0)`.

@@ hints
- `withColumnRenamed` s'enchaîne : un appel par colonne.
- `spark.read.option("header", "true").csv(...)` pour les zones : sans schéma, `LocationID` est une chaîne, et Spark la convertit pour comparer. Un `cast("int")` rend la jointure plus nette.
- Spark choisit le broadcast tout seul quand une table fait moins de 10 Mo (`spark.sql.autoBroadcastJoinThreshold`) : `F.broadcast` le rend explicite.
- Les deux tables de la leçon 7 sont dans `data/report/revenue/green/` et `.../yellow/`.

@@ solution
`jointures.py` :

~~~python
from pyspark.sql import SparkSession, functions as F

spark = SparkSession.builder.master("local[*]").appName("jointures").getOrCreate()

green = spark.read.parquet("data/report/revenue/green/") \
    .withColumnRenamed("amount", "green_amount") \
    .withColumnRenamed("number_records", "green_number_records")
yellow = spark.read.parquet("data/report/revenue/yellow/") \
    .withColumnRenamed("amount", "yellow_amount") \
    .withColumnRenamed("number_records", "yellow_number_records")

joined = green.join(yellow, on=["hour", "zone"], how="outer")
print(joined.count(), "lignes")
joined.explain()   # SortMergeJoin

zones = spark.read.option("header", "true").csv("data/zones/taxi_zone_lookup.csv") \
    .withColumn("LocationID", F.col("LocationID").cast("int"))

result = joined.join(F.broadcast(zones), joined.zone == zones.LocationID) \
    .drop("LocationID", "zone")
result.explain()   # BroadcastHashJoin
result.write.parquet("data/report/revenue/total/", mode="overwrite")
spark.stop()
~~~

La sortie : `1803705 lignes`, puis deux plans, l'un avec `SortMergeJoin`, l'autre avec `BroadcastHashJoin`.
