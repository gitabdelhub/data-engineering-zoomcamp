### 3. Comprends to_sql

`df.to_sql(...)` écrit un DataFrame dans une table. Trois paramètres comptent ici :

| Paramètre | Rôle |
| --- | --- |
| `name` | le nom de la table |
| `con` | la connexion, le `engine` créé avec `create_engine` dans la leçon |
| `if_exists` | que faire si la table existe déjà : `"fail"` (erreur), `"append"` (ajouter les lignes à la suite) ou `"replace"` (refaire la table) |
| `index` | `True` par défaut : pandas ajoute alors une colonne `index` avec les numéros de ligne |

Choisis la valeur de `if_exists` qui donne **le même résultat** si tu relances la cellule, et la valeur de `index` qui évite la colonne en trop.

### 4. Vérifie deux fois

Lance ta cellule **deux fois**, puis dans pgcli : `SELECT COUNT(*) FROM zones;` doit répondre 265, pas 530. `\d zones` montre les colonnes : pas de colonne `index`.

@@ solution
~~~python
import pandas as pd
from sqlalchemy import create_engine

# La connexion : utilisateur:mot_de_passe@machine:port/base
engine = create_engine("postgresql+psycopg://root:root@localhost:5432/ny_taxi")
url = "https://github.com/DataTalksClub/nyc-tlc-data/releases/download/misc/taxi_zone_lookup.csv"

df_zones = pd.read_csv(url)            # petit fichier : on le lit d'un coup
# replace : la table est refaite à chaque exécution, donc jamais de doublons
# index=False : pas de colonne « index » en plus
df_zones.to_sql(name="zones", con=engine, if_exists="replace", index=False)
print(len(df_zones))   # 265
~~~
Pour aller plus loin : lance `SELECT * FROM zones WHERE "LocationID" = 265;` et compare avec la dernière ligne du fichier CSV. Une valeur a changé en route. Pourquoi ? Garde la réponse en tête pour le défi du module.
