@@ guide
### 1. Pars du script de la leçon

Copie le script officiel dans ton dossier, pour le modifier sans toucher au cours :

~~~bash

~~~

`../../..` remonte de trois dossiers, jusqu'à la racine du fork. Lance `uv run python ingest_data.py --help` : tu vois les options actuelles.

### 2. Comprends une option click

Chaque `@click.option` ajoute une option à la commande. Sa valeur arrive dans le paramètre de la fonction qui porte le même nom, sans les tirets : `--target-table` devient `target_table`. Le `type` peut **valider** la valeur tout seul. Exemple, pour une taille de t-shirt :

~~~python
@click.option('--taille', type=click.Choice(['S', 'M', 'L']), default='M', help='Taille du t-shirt')
~~~

Avec `--taille XL`, click refuse et affiche une erreur, avant que ton code ne démarre. Pour un nombre dans un intervalle, c'est `click.IntRange(min, max)`.

### 3. Ajoute --color et protège --month

- Ajoute une option `--color` qui n'accepte que `yellow` ou `green`, puis ajoute `color` aux paramètres de `def run(...)`.
- Change le `type` de `--month` pour qu'il refuse tout ce qui n'est pas entre 1 et 12.

Teste : `uv run python ingest_data.py --month 13` doit être refusé immédiatement, sans rien télécharger.

### 4. Construis l'adresse selon la couleur

Regarde la variable `url` du script : `yellow` y apparaît deux fois. Remplace-les par la valeur de `color`. Dans une f-string, `{color}` insère la valeur.

### 5. Les dates selon la couleur

`parse_dates` dit à pandas quelles colonnes lire comme des dates. Chez les jaunes : `tpep_pickup_datetime` et `tpep_dropoff_datetime`. Chez les verts : `lpep_…`. Déplace `parse_dates` **dans** la fonction `run`, et choisis la bonne liste selon `color`, par exemple avec un `if` :

~~~python
if color == "yellow":
    ...
else:
    ...
~~~

### 6. Le nom de la table par défaut

Mets `default=None` à `--target-table`. Dans la fonction, si `target_table` est vide, utilise `<couleur>_taxi_trips`. `target_table = target_table or "…"` fait exactement ça : `or` garde la première valeur non vide.

### 7. Lance et vérifie

Avec le Postgres de la leçon démarré : `uv run python ingest_data.py --color green --year 2021 --month 1`. Puis dans pgcli, compte les lignes de `green_taxi_trips`, et regarde le type des colonnes de dates avec `\d green_taxi_trips` : elles doivent être en `timestamp`.

@@ hints
- Les fichiers verts sont dans la même release, sous `.../download/green/green_tripdata_<année>-<mois>.csv.gz`.
- Chez les taxis verts, les dates s'appellent `lpep_pickup_datetime` et `lpep_dropoff_datetime`. Les colonnes de `dtype` existent dans les deux couleurs : seul `parse_dates` doit changer selon la couleur.
- click a des types qui valident tout seuls : regarde `click.Choice` et `click.IntRange`.

@@ solution
Le script complet, à partir de celui de la leçon. Les lignes qui changent sont commentées.

~~~python
#!/usr/bin/env python
# coding: utf-8

import click
import pandas as pd
from sqlalchemy import create_engine
from tqdm.auto import tqdm

# Les colonnes de ce dictionnaire existent chez les jaunes ET chez les verts :
# il marche tel quel pour les deux couleurs.
dtype = {
    "VendorID": "Int64",
    "passenger_count": "Int64",
    "trip_distance": "float64",
    "RatecodeID": "Int64",
    "store_and_fwd_flag": "string",
    "PULocationID": "Int64",
    "DOLocationID": "Int64",
    "payment_type": "Int64",
    "fare_amount": "float64",
    "extra": "float64",
    "mta_tax": "float64",
    "tip_amount": "float64",
    "tolls_amount": "float64",
    "improvement_surcharge": "float64",
    "total_amount": "float64",
    "congestion_surcharge": "float64"
}


@click.command()
# click.Choice refuse toute autre valeur que yellow ou green
@click.option('--color', type=click.Choice(['yellow', 'green']), default='yellow', help='Couleur des taxis : yellow ou green')
@click.option('--pg-user', default='root', help='PostgreSQL user')
@click.option('--pg-pass', default='root', help='PostgreSQL password')
@click.option('--pg-host', default='localhost', help='PostgreSQL host')
@click.option('--pg-port', default=5432, type=int, help='PostgreSQL port')
@click.option('--pg-db', default='ny_taxi', help='PostgreSQL database name')
@click.option('--year', default=2021, type=int, help='Year of the data')
# click.IntRange refuse 13 avant même que la fonction démarre
@click.option('--month', default=1, type=click.IntRange(1, 12), help='Mois des données, de 1 à 12')
# None par défaut : le nom de la table est choisi plus bas selon la couleur
@click.option('--target-table', default=None, help='Table cible (par défaut : <couleur>_taxi_trips)')
@click.option('--chunksize', default=100000, type=int, help='Chunk size for reading CSV')
def run(color, pg_user, pg_pass, pg_host, pg_port, pg_db, year, month, target_table, chunksize):
    """Ingest NYC taxi data into PostgreSQL database."""
    # La couleur choisit le dossier et le nom du fichier
    prefix = 'https://github.com/DataTalksClub/nyc-tlc-data/releases/download'
    url = f'{prefix}/{color}/{color}_tripdata_{year}-{month:02d}.csv.gz'

    # tpep_… chez les jaunes, lpep_… chez les verts
    letter = 't' if color == 'yellow' else 'l'
    parse_dates = [f'{letter}pep_pickup_datetime', f'{letter}pep_dropoff_datetime']
    target_table = target_table or f'{color}_taxi_trips'

    engine = create_engine(f'postgresql+psycopg://{pg_user}:{pg_pass}@{pg_host}:{pg_port}/{pg_db}')

    df_iter = pd.read_csv(
        url,
        dtype=dtype,
        parse_dates=parse_dates,
        iterator=True,
        chunksize=chunksize,
    )

    first = True

    for df_chunk in tqdm(df_iter):
        if first:
            df_chunk.head(0).to_sql(
                name=target_table,
                con=engine,
                if_exists='replace'
            )
            first = False

        df_chunk.to_sql(
            name=target_table,
            con=engine,
            if_exists='append'
        )

if __name__ == '__main__':
    run()
~~~
