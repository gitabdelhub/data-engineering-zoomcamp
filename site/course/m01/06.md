@@ brief
- On transforme le notebook en script : `jupyter nbconvert --to=script`, puis on nettoie le code.
- La bibliothèque **click** transforme les paramètres en options de ligne de commande (`--pg-user`, `--pg-host`…), avec des valeurs par défaut et une aide automatique (`--help`).
- Le script complet est dans le dossier officiel `01-docker-terraform/pipeline/ingest_data.py`. Il a aussi `--year`, `--month` et `--chunksize`.

@@ codespaces

@@ predict

@@ predict-answer
Il utilise les **valeurs par défaut** de chaque option : `root`/`root` sur `localhost:5432`, base `ny_taxi`, et dans le script officiel janvier 2021 vers la table `yellow_taxi_data`.
